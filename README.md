# Interactive Drawing Canvas

A simple and interactive drawing application built with **HTML5 Canvas**, **CSS3**, and **Vanilla JavaScript**. Users can draw freely using their mouse, change brush colors, and clear the canvas with a single click.

---

# Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Page Structure |
| CSS3 | Styling |
| JavaScript (ES6) | Application Logic |
| HTML5 Canvas API | Drawing Surface |

---

# Installation

## Clone the repository

```bash
git clone https://github.com/Zunairatahir/Canvas-code.git
```

## Navigate to the project

```bash
cd Canvas-code
```

## Run the project

Simply open

```text
index.html
```

in your preferred web browser.

You can also use the **Live Server** extension in Visual Studio Code.
